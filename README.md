Surya Drishti — Space Weather Monitoring System

An interactive dashboard for monitoring space weather conditions and understanding their potential impact on satellite communication, GNSS navigation, and other space-based systems.

🚀 Live App: https://suryadrishti.streamlit.app/

Features

- Space weather monitoring dashboard
- Space weather alerts and visualizations
- Information about solar activity and its potential impacts

Built With

- Python
- Streamlit
- Data visualization libraries
